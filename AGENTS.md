# PerpCity SDK Notes

## Contract source

SDK 1.x targets perpcity-contracts tag `v1.0.0` (`0df4208`) with `lib/beacons` at `f762da1`,
and nothing else. v0.x markets (58b42b7, v0.2.2-upgradeable) are served by SDK `0.19.x`.

- `src/abis/*.ts` are generated by `scripts/sync-abis.ts` from a build of that tag. Do not edit
  them by hand. The script refuses any other commit.
- `PERP_ABI` is the Perp artifact plus the `Errors.sol` set: the libraries revert with errors
  (`MarginRatioTooLow`, `MaxTotalFeeExceeded`, ...) that the Perp artifact does not list, and
  viem decodes a revert only with the ABI passed to the call.
- Deployed addresses (`src/deployments.ts`) come from perpcity-deployments PR #3 (README at
  `2c333a5`).

## Contract model (v1)

- Each market is a `Perp` behind an ERC1967 proxy, created by `PerpFactory.createPerp(owner,
  governor, modules, emaWindow, latency, salt, withdrawalConfig)`. The factory reads the beacon
  with `latency`, so the beacon must be fresh first.
- Positions have no ERC721: the owner is `positionOwner(posId)`, cleared on a full close.
  Positions cannot be transferred.
- Every write has a `deadline`; taker writes have `maxTotalFee`; `adjustTaker` has
  `reduceOnly`. Makers also have `moveMaker`.
- The v1 mark, funding and margin math is different from v0.x. The SDK does not reimplement
  it: it reads `previewPosition` and the other views. Never map a v1 perp to v0 math.
- USDC payouts go through the market's `WithdrawalController` (instant up to a rate limit,
  else a queued claim).

## Kept from 0.x

Build-independent Uniswap v4 pool math: tick math, conversions, `getAmountsForLiquidity`,
`makerLimits`, the tick-map reader and the exact swap walker. The v1 pool is a real v4 pool
with fee 0 and the `PerpGuardHook`; swaps and liquidity changes go through `PoolManager`.

## Verification

```sh
pnpm exec tsc --noEmit
pnpm lint
pnpm test:unit
ARBITRUM_SEPOLIA_RPC_URL=https://sepolia-rollup.arbitrum.io/rpc pnpm test:integration
pnpm build
```

The integration suite needs `anvil`. It forks Arbitrum Sepolia and makes its own v1 market,
because no v1 market is listed on Sepolia yet.
